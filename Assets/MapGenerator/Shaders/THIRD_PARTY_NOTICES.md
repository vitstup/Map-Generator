# Unity URP terrain interfaces

The terrain ShaderLab property declarations/pass interfaces are adapted from the installed Unity Universal Render Pipeline. Terrain vertex, lighting and utility functions are included from that package at compile time. Stochastic sampling and matte surface composition are project code.
